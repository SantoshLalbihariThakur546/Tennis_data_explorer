# Submission checklist
- [ ] Obtain Sportradar API key and verify access to all three feeds.
- [ ] Configure `.env` locally; never commit it.
- [ ] Install dependencies and initialize database.
- [ ] Run collection script and verify six tables.
- [ ] Execute SQL analytics queries.
- [ ] Run `pytest -q`.
- [ ] Test every Streamlit page, filter and CSV export.
- [ ] Push code, SQL, tests and documentation to GitHub.
- [ ] Configure Streamlit Cloud secrets and managed database for persistent deployment.
